# Alineación de Objetivos Estratégicos con Servicios de TI – Panadería Don Juan

| Objetivo Estratégico | Descripción | Servicio de TI Alineado | Beneficios Esperados |
|----------------------|-------------|--------------------------|----------------------|
| **1. Mantener alta calidad y variedad de pan** | Ofrecer productos consistentes en sabor y presentación mediante procesos estandarizados. | Sistema digital de recetas con pantalla táctil en zona de producción. | - Homogeneidad en la calidad<br>- Menos errores<br>- Capacitación rápida<br>- Agilidad en cambios de recetas |
| **2. Optimizar y controlar los procesos de producción** | Necesidad de supervisar y registrar todas las etapas de producción para mejorar la eficiencia. | Software de control de producción y seguimiento de lotes. | - Producción trazable<br>- Reducción de mermas<br>- Mejora de tiempos<br>- Informes para toma de decisiones |
| **3. Expandir canales de venta y distribución** | Gestionar ventas en línea y pedidos mayoristas de forma eficiente y automatizada. | Plataforma web para ventas B2C y sistema de pedidos B2B con rutas y entregas. | - Más ventas<br>- Menos errores en pedidos<br>- Fidelización<br>- Ahorro en coordinación manual |
| **4. Llevar control financiero eficiente y automatizado** | Automatizar el manejo de ingresos, egresos, cuentas por cobrar y documentación tributaria. | Sistema contable y financiero integrado. | - Visión financiera clara<br>- Menos carga administrativa<br>- Cumplimiento con SUNAT<br>- Decisiones basadas en datos |
| **5. Gestionar eficazmente proveedores y materias primas** | Asegurar stock, reducir pérdidas por vencimientos y organizar relaciones con proveedores. | ERP con módulos de compras, proveedores e inventario. | - Menos desperdicios<br>- Mejores compras<br>- Control de insumos<br>- Alertas de stock mínimo |
